# ANTARES Security Architecture

## Por qué existe este sistema
No es desconfianza hacia los agentes.
Es reconocer que son herramientas poderosas que deben operar
con barandas para proteger al desarrollador, al proyecto y al
propio agente de daños accidentales.

## Principio Operacional
- El agente tiene autonomía dentro del workspace
- El agente NO tiene llaves del castillo
- El humano es el arquitecto de seguridad
- El agente es el ejecutor controlado

## Workspace como Sandbox
/antares/ es un microcosmos aislado donde el agente puede operar
sin riesgo de daño colateral. Es un entorno de confianza construido
sobre restricciones técnicas claras, no sobre confianza ciega.
