# ANTARES — Product Requirements Document

## Overview
ANTARES es una plataforma moderna de automatización inteligente diseñada para equipos creativos y workflows digitales modernos.

El objetivo del proyecto es crear una experiencia premium, minimalista y tecnológica evitando clichés visuales típicos de productos AI genéricos.

---

## Design Direction

- Editorial tech minimal
- Dark premium interface
- Strong typography
- Clean spacing system
- Cinematic atmosphere
- Minimal but expressive interactions

---

## Frontend Stack

- HTML5
- CSS3
- JavaScript Vanilla

---

## Goals

- Aprender frontend moderno
- Aprender arquitectura UI
- Aprender AI orchestration
- Crear un proyecto portfolio-ready
- Construir design systems reales

---

## Constraints

- Mobile-first
- No frameworks por ahora
- No librerías innecesarias
- Código limpio y reusable
- Evitar estilos genéricos SaaS AI
