# Nyx Direction | Visual & Cinematic Philosophy

Este es el espacio de trabajo de Nyx. Aquí se define el "sentir" de ANTARES antes de que se convierta en código.

---

## 1. Spacing Philosophy (The Breathing)
- **Negative Space as Content:** El espacio vacío no es ausencia de información, es lujo visual.
- **Micro-delicacy:** Espaciados pequeños para agrupar información técnica; espaciados masivos para separar conceptos editoriales.
- **Rhythm:** Alternar entre densidades para guiar el ojo sin esfuerzo.

## 2. Typography Rhythm
- **Contrast:** Títulos masivos en `Plus Jakarta Sans` contra textos de apoyo técnicos y pequeños en `Inter`.
- **Tracking:** Tracking abierto (`0.05em`+) para mayúsculas y branding; tracking cerrado para lectura fluida.
- **Hierarchy:** Máximo 3 niveles de información por sección. Menos es más.

## 3. Visual Hierarchy & Composition
- **Architectural Layouts:** Estructuras que se sientan construidas, no apiladas.
- **Asymmetry:** Uso deliberado de la asimetría para generar interés visual y romper la monotonía de "SaaS genérico".
- **Focus Points:** Un solo elemento debe dominar la escena (Hero Image, Hero Text o una interacción).

## 4. Cinematic Principles (Atmosphere)
- **Lighting:** Uso de gradientes de iluminación que emulen "fog" o luces de estudio tenues sobre fondo negro.
- **Depth:** Superposición de capas con desenfoque (blur) para crear profundidad de campo.
- **Texture:** Uso de ruido (grain) sutil para dar una sensación orgánica y táctil al entorno digital.

## 5. Motion Philosophy
- **Inertia:** Los movimientos deben sentirse físicos, con inercia y gravedad (cubic-bezier 0.16, 1, 0.3, 1).
- **Subtlety:** Animaciones que se perciben más que se ven. Nada de rebotes "infantiles" o efectos ruidosos.
- **Purpose:** Cada movimiento debe confirmar una acción o revelar información.

## 6. Color Balance
- **Deep Black Base:** `#020617` como lienzo infinito.
- **Muted Accents:** El color se usa con cuentagotas. Indigo (`#818cf8`) solo para puntos de enfoque críticos.
- **Greyscale Palette:** La mayor parte de la UI vive entre blancos puros, grises humo y transparencias.

## 7. Section Composition
- **The Golden Grid:** Alineación basada en una cuadrícula estricta de 12 columnas.
- **Content Density:** Mantener un ratio de 30% contenido / 70% aire.

## 8. Premium Interaction Rules
- **Feedback Elegante:** Hover effects que oscurecen o aclaran sutilmente, nunca cambios drásticos de color.
- **Transition Continuity:** Los elementos nunca desaparecen; se desplazan o se funden.
