# Agent Permission Levels

## Level 1 — Read Only
Puede:
- leer archivos
- analizar código
- generar sugerencias

No puede:
- modificar archivos
- ejecutar comandos

---

## Level 2 — Workspace Editor
Puede:
- editar archivos dentro de /antares
- crear componentes
- refactorizar código

No puede:
- instalar dependencias
- acceder a red
- modificar reglas

---

## Level 3 — Supervised System Agent
Puede:
- ejecutar tareas avanzadas
- instalar paquetes aprobados
- ejecutar builds

Requiere:
- aprobación humana explícita
- supervisión activa
